# LicenseForge

Open-source, Kubernetes-native software licensing. Define products, features and plans; issue licenses; control activations online **and** in air-gapped environments.

- **Apache-2.0**, everything: server, SDKs, Helm chart.
- **Signed licenses** (Ed25519) that verify offline.
- **Kubernetes-native**: Helm chart, cluster-bound licenses, in-cluster agent.
